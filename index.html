METHOD

三步，缺一不可

01

需求即规格

说不清要什么，它就给你一个看起来对、其实不能用的东西。模糊是我的问题，不是它的。

02

生成即草稿

它几秒给出初版，这是它最强的地方。但草稿不是成品，中间隔着判断。

03

验收即能力

跑标准、看报错、定位根因。能让它把活干对的人，才真正用它。

PITFALLS

我踩过的五个坑

每一条都改了不止一遍。

01

删了元素，没删数据

页面刷新之后，删掉的行又回来了。后来明白：页面只是影子，改数据才算数。

02

监听器写在了渲染函数里

每渲染一次多一个监听器，控制台越点报错越多。改成绑在不变的父元素上，只绑一次。

03

1fr 不是「可以随便小」

它能缩到的最小值，是里面内容的最小宽度。六列挤在手机宽度里，字全被压扁。

04

计时器变量声明在了函数里

每次点击都是全新的一对变量，上一轮那两条计时器根本没被清掉——提示条提前消失。

05

写完不看就跑

购物车合计显示「￥8」，实际应该是「￥1984」。数字自己会喊，只是我没抬头看。

CASE / 我抓到它一个错

页面看着没事，控制台在喊

AI 把点击监听器写进了渲染函数里。每渲染一次，就多一个监听器； 旧的还在，只是它手里的行已经被删掉了。 

// 控制台
Cannot set properties of undefined (setting 'gou')

// 根因：旧监听器拿到已删除的行，indexOf 返回 -1
const c = Array.from(document.querySelectorAll(".hang")).indexOf(hang)
dingdan[-1].gou = true          // 崩在这里

// 改法：只绑一次，绑在不会重建的父元素上
kapianzubox.addEventListener("click", ...)

AI 会犯错。我的用处，就是能指出它错在哪。

PROCESS

一个课表，三个版本

V1

把监听器绑在每一行

行一删就失效，新生成的行没有任何反应。当时以为是浏览器的错。

V2

搬进渲染函数

能用了，但每渲染一次就多一个监听器，控制台越点报错越多。

V3

绑在不会死的父元素上

一个监听器管所有行，无论重建多少次。这才是事件委托。

手机上还崩过一次：六列挤进 343 像素，字被压成一条。
后来改成卡片单列、每行自己重排——这些过程比结果更能说明问题。

02 — 03 / PROCESS

从「不行」那一类里，
走到这里。

这条路我走过三次想放弃。

STORY

我的故事

中职那几年，我大概是被默认归到「不行」那一类里的。

学校强制住宿，周六下午才放人。我骑车在街上绕，一圈又一圈——不是想去哪儿，是不知道能去哪儿。风打在脸上，脑子里是空的。

高二那年，一个同学把我拽去面试竞赛班。教室在四楼最里头，我站在门口没敢进。我对计算机一窍不通，连打字都要低头找键。

但屏幕亮起来的那一刻，我第一次觉得有一样东西是我能看懂的：一行字，换一个词，颜色就变了。那是我自己敲出来的。

那半年我几乎住在机房里。放学别人去打球，我留下来把白天没看懂的标签一个一个试过去。第一次让一张图片居中，我截了图发给同学，他回了一个「牛」。

后来我进了竞赛班。每周三晚上训练，我坐在最后一排，听得一知半解，回去再查一遍。慢慢地，别人说的话我能听懂一半了。

第一个比赛很简单。我提前想好了拿奖之后第一个电话打给谁。结果公布那天，名单上没有我。

接下来两个更难。人工智能要学 Python，应用软件开发要学 Java、Vue、MySQL。我连「变量」是什么都说不清，别人翻两页的书，我要读一整晚。

那阵子我怀疑的不是别人信不信我，是我到底能不能学会。

后来我每天学到深夜，台灯亮到宿管来敲门。那两个比赛，一个拿的是人工智能，一个拿的是应用软件开发。

是她把我拉进去的。改变一个人的方向，有时候只要一句「你要不要来试试」。要不是她，我这辈子可能都不会往计算机这边走。

回头看，我人生里每一次转弯，都不是我自己拐的——有人拉我，有人推我，有人在前面先替我试了一次。

这一次，我想自己推自己一把。
01

“这些练习到底有没有用”

连着几周做同一类页面，每天写的东西长得差不多，我开始觉得在原地打转。

校准：把同一个东西写三遍之后，手会记住。不知道够不够用，但我知道停下来的话一定不够。

02

“AI 几秒钟就能做完，我学它干嘛”

我让 AI 写了一遍我苦思半天的功能，几秒钟。那种感觉很糟——我花的时间还有什么意义。

校准：后来它写错了一个地方，是我第一个看出来的。它替我打字，判断还得我来。

03

“我是不是学得太慢”

两个月才做出一个课表，别人可能一周就做完了。我分不清自己是慢，还是只是在按自己的方式走。

校准：不知道。但两年前我连标签是什么都不知道。

我来这里，最直接的原因是：一个人摸索两个月，我分不清哪些是必经之路，哪些是我走了弯路。

我需要有人告诉我：哪一步是弯路，哪一步是必经的。
